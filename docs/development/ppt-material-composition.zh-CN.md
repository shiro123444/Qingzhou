# 文字和文档组合为分镜，再继续制作 PPT

2026-10-14，本轮接通资料处理、带来源的分镜、跨模板能力选择、素材规划与可编辑 PPT 导出。沿用附件上传和 `@lobechat/file-loaders`，文档操作经 Cordis 原子工具目录发现。主规划实际使用 DeepSeek，模板视觉复核使用同一已配置服务中的 Gemini。

## 使用方式

在 PPT 对话中同时上传 PDF、Word 或文字资料，也可以直接粘贴文字。例如：

> 结合这份 Word 和 PDF 制作教学汇报。先检查资料目录，读取相关章节，把 PDF 第 2–5 页拆成文件并转成 Markdown。根据资料组织六页分镜，保留来源，再自主组合能力库中的模板布局与素材继续制作。

Agent 自主决定阅读与转换顺序。文档目录不算已读正文；长文可以直接读取后部段落，不再静默截掉后半篇。分镜包含主张、要点、视觉建议、备注和来源段落。优化大纲与生成 PPT 都保留结构化资料。界面展示每份资料的已读范围，以及实际转换、拆分得到的下载文件。

```mermaid
flowchart LR
  A[多份附件或粘贴文字] --> B[页段目录与版本指纹]
  B --> C[按主题阅读原文]
  B --> D[PDF 拆页 / 转文字]
  D --> C
  C --> E[带来源的逐页分镜]
  E --> F[自主选择跨模板能力]
  F --> G[复用或生图 / 分层排版]
  G --> H[视觉复核 / 可编辑 PPT]
```

## 可组合操作

| 操作 | 实际结果 |
| --- | --- |
| `context.document.fromText` | 把粘贴文字或明确标识的草稿保存为账号内文字附件 |
| `context.document.inspect` | 分页查看目录、总段数、版本指纹和无正文页 |
| `context.document.read` | 精确读取 1–8 段正文，带原始页码或逻辑节号 |
| `context.document.convert` | 把全部或指定段落转成可下载 Markdown / TXT，保留页段标签和来源 |
| `context.document.splitPdf` | 按 1-based 闭区间拆出实际 PDF，原文件保持不变 |
| `planning.outline` | 基于已读证据生成分镜，校验 `sourceRefs`，来源写入备注 |

工具返回的新附件可以继续阅读和转换；其 ID 和下载文件随对话保留。正文与来源单独持久化，不依赖会压缩的研究工具回执。恢复对话和优化分镜时，服务端重新读取账号内原文件，拒绝失效版本或不属于该账号的资料。资料变动也会使内容与视觉分镜缓存失效。

PDF 使用解析器的真实页码；Word、文字资料中的逻辑段落不伪装成物理页。修复了中文 CID 字体 PDF 缺少本地 CMap 而被误读为空页的问题，并保留部署所需的字符映射与字体资源。

## 实际验收

使用明确标注“功能验收样例”的三页中文 PDF，以及十五段长文。DeepSeek 自主读取 PDF 全部三页及长文末尾两段，实际拆出 PDF 第 2–3 页并生成 Markdown，然后产生六页带来源的分镜。

同一份分镜经生产 PPT 链路选取三个已学习模板的能力，复用上一轮真实生成的校园、课堂和机制插图，完成六页 PPT。这次没有新增生图。最终文件经 PowerPoint 原生渲染检查全部六页，来源写入六页备注；12 门课程、3 次研讨保留为计划，37 万元保留为预算。清理了上一阶段操作指令误入封面正文的问题，并修正了文件卡片标题长度。拆出 PDF 的第二页与原 PDF 第三页渲染像素完全相同。

交付目录：`E:/林清桐/PPT模板/清舟验收/资料到分镜验收`，包含 PPTX、六页预览、拆分 PDF、转换正文、分镜与来源和结构核验结果。

## 验证范围与限制

- 本轮运行 13 个相关测试文件、165 个测试，全部通过；包括附件隔离、真实 PDF 拆分、长文末尾、多来源分镜、未知引用、恢复时的原文重取、界面上下文传递和 79 个 API 回归测试。
- 本轮相关服务与新组件的专项类型检查通过；修改文件 ESLint 无错误。
- 整仓类型检查仍受不同工作区共享依赖版本不一致影响；统一源码别名后的检查仍有 153 个既有错误，本轮新增文档模块没有类型错误。
- 没有完成登录后本地应用的全流程验收：本机 PostgreSQL / Docker 服务此前未运行。实际模型、资料处理和 PPT 导出验证均在本机真实运行时完成。
- 当前转换输出 Markdown / TXT；PDF 拆页保留页图形。不支持扫描 PDF 自动 OCR、PDF 转成可编辑 Word，也不宣称文字转换保留复杂表格和页面版式。无正文页面明确返回目录提示，整份文字转换不会悄悄遗漏这些页。
- 每轮最多持有 96 个已读段落；单段最多 1800 字符。超出时要求按主题分批，已读内容不被静默丢弃。
