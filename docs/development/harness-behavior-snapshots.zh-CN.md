# 行为版本与运行快照：第一个实现增量

2026-10-22。对应[下一阶段设计 A](harness-next-architecture.zh-CN.md#8-建议执行顺序与验收闸门)。本记录限定本次实现和验证范围。

## 行为变化

服务端 `AiAgentService.execAgent` 现在先固定合并默认值后的作者配置，再应用本次模型/provider 覆盖、内置宿主配置、页面/任务指令和单次 `instructions`。提示词组合同时记录 `author`、`host`、`task` 来源段；捕获时核对来源段与实际组合结果，不一致则在创建 operation 前拒绝。

新的服务端运行使用 schema 2 行为版本，以及单独计算摘要的运行快照。两者共同组成绑定，不再以完整的单次运行配置定义 Agent 默认行为。

- 行为版本保存作者配置、默认模型绑定、上下文策略、完整技能材料及作者声明的插件集合、Agent 文档和实现标识。
- 运行快照保存有效配置、本次模型绑定、带来源的提示词段、实际技能启用集合、工具目录、初始上下文/消息和入口、设备、时区、记忆等已捕获输入。来源版本 ID 与最终选中的行为版本 ID 分别可追溯。
- 同一作者配置及技能/文档材料下，Chat、page、task 的行为版本保持一致。页面工具、任务标识、单次指令和临时模型覆盖只改变运行快照。

共享契约和解析函数位于 [`agent-runtime/harness.ts`](../../packages/agent-runtime/src/harness.ts)，服务端捕获/恢复位于 [`agentRuntime/harness.ts`](../../src/server/services/agentRuntime/harness.ts)。不保存执行句柄，凭证字段沿用过滤规则。

## 采用、恢复与兼容

采用指令时只替换作者段，再与这次运行固定的 host/task 段组合；原有工具目录、动态启用集合和其他配置不被候选整体覆盖。作者指令为空、原先使用内置提示词时，内置提示词仍作为宿主段保留。

临时模型或 provider 与已验证默认绑定不兼容时，本次使用源行为配置；它不清除活动指针。后续恢复默认模型的运行仍可使用已采用候选。用户修改作者配置、技能正文或文档材料会改变源版本；下一次完整捕获继续按既有规则使旧采用失效。

这一步的作用域策略是同一账号/Agent 共享作者行为，运行入口及临时模型覆盖属于本次输入。没有新增按任务 ID 建立的永久默认配置，也没有开放跨账号或跨 Agent 复用。更细的能力资格和配置档策略仍属于后续增量。

schema 1 已保存任务继续按原格式校验和恢复。缺少可信来源段的直接/自定义创建入口继续固定原格式快照，不向公共学习源登记组合后的配置。不完整材料也不登记新的可实验源。schema 1 已有实验和证据不被重写；新 schema 2 源不会把旧候选自动提升为已验证新版候选。

旧运行继续使用自己的完整绑定，不在续跑时查询最新活动指针。schema 2 绑定缺少运行快照、快照摘要不符、运行 ID 或账号作用域不符时拒绝恢复。当前权限检查和执行句柄仍由宿主管理。

操作 metadata、状态管理器和最终 trace 都保留 revisionId/snapshotId 绑定。最终 trace 只保存绑定引用，不复制运行快照的私有正文。

## 普通执行与试跑的共同部分

schema 2 普通恢复和纯文本 probe 共用 `resolveHarnessMaterial`，执行时仍通过现有 Cordis 指令策略和上下文管线。协调器以 `verifyHarnessRevision` 单独验证行为版本；候选差分保持源 schema，避免将 schema 2 候选意外降回旧格式。

probe 使用登记任务的中性输入，不读取起源页面/任务的运行快照。它保持已有的纯文本限制：无工具、固定输入大小/输出上限、独立匿名选择和既有调用预算/取消流程。schema 2 probe 在调用模型前检查模型/provider 是否与版本绑定一致。

匿名选择不加载候选指令、Agent 文档或技能。受控上下文测试检查实际模型请求，证明候选作者指令与固定文档进入回答上下文，原页面私有任务没有进入，选择上下文也没有这些材料。

这只是可编辑配置的共同解析及纯文本资格验证，不代表普通运行与 probe 在检索、工具、设备、多模态、动态 persona 或全部模型参数上已具备完整回放一致性。客户端仍固定其独立客户端快照，服务端提供的兼容作者指令投影同时覆盖 schema 1/2；本次未将客户端转换为服务端完整实验材料。

回归集合包含：行为/快照新测试，schema 1 恢复，AgentRuntimeService 创建和绑定落盘，AiAgent 内置/page/task/模型覆盖入口，AgentStateManager、RuntimeExecutors、客户端 streamingExecutor、认证实验路由、提案/技能暂存、串行预算，以及 PPT 工作区和生产装配代表页测试。
